# Проект
Сервис подбора треков по звучанию (рабочее название song-vibes-check).
Монорепозиторий: Go API (cmd/, internal/), user-service (Go), mood-service (Python),
pipeline/ (Python, офлайн-подготовка данных), lab-events/ (Redpanda + ClickHouse).

# Правила
- Не трогай существующие сервисы без явной просьбы.
- Секреты только через переменные окружения; .env в git не коммитить.
- Go: gofmt, go vet, тесты рядом с кодом. Python: типы и requirements.txt с зафиксированными версиями.
- Прежде чем писать код, прочитай реальные данные и файлы и опиши, что нашёл.
- Маленькие коммиты, сообщения на английском в стиле conventional commits.
